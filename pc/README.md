# 네이버 블로그 자동 글쓰기 — PC 버전 (Windows)

PC를 켜 두면 아래 순서가 돌아갑니다.

1. **최신 키워드 검색 (자동)** — 매일 05:47에 웹에서 최신 뉴스·정부 발표를 검색해 블로그 카테고리에 맞는 키워드 4개를 고릅니다(설정에서 변경).
2. **글쓰기 (자동)** — 키워드마다 자료를 더 찾아보고 3,000자 이상 초안과 이미지 카드 내용을 씁니다.
3. **검토·확인 (직접)** — PC 브라우저나 아이패드로 검토 앱을 열어 [직접 쓰기]·[공고 확인] 자리를 채우고 선정합니다.
4. **예약 발행 (자동)** — 발행 시간을 정하고 '예약 시간에 PC가 자동 발행'을 누르면, 그 시간에 이 PC의 크롬이 네이버 글쓰기 화면에 제목·본문·이미지·태그·카테고리를 넣고 발행합니다.

네이버 로그인은 처음 한 번, 열리는 크롬 창에서 **직접** 합니다. 비밀번호는 이 프로그램이 저장하지 않고, 로그인 상태는 `data/naver_profile` 폴더(이 PC의 크롬 프로필)에만 남습니다.

## 설치 (처음 한 번)

1. **파이썬 3.10 이상**을 설치합니다: https://www.python.org/downloads/ — 설치 첫 화면에서 **"Add python.exe to PATH"** 를 꼭 체크하세요.
2. 이 `pc` 폴더를 PC의 원하는 곳(예: `문서\블로그자동`)에 둡니다.
3. **`설치.bat`** 을 더블클릭합니다. 몇 분 걸립니다.
4. **글쓰기에 쓸 Claude 연결** — 둘 중 하나:
   - **Claude Code가 이 PC에 설치돼 있으면 그대로 사용**합니다(내 Claude 계정 사용량). 명령 프롬프트에서 `claude` 를 한 번 실행해 로그인돼 있는지 확인하세요.
   - 없으면 **Anthropic API 키**를 씁니다(사용한 만큼 따로 요금). 윈도우 검색 → "시스템 환경 변수 편집" → 환경 변수 → 새로 만들기: 이름 `ANTHROPIC_API_KEY`, 값 `sk-ant-...`. 그리고 `config.json`의 `"writer"`를 `"api"`로 바꿉니다.
5. **`네이버 로그인.bat`** 을 실행하고, 열린 크롬 창에서 네이버에 로그인합니다. "로그인 상태 유지"를 켜 두면 오래 유지됩니다.

## 매일 쓰기

1. **`실행.bat`** 을 실행합니다. 검은 창에 주소와 **접속 비밀번호(6자리)** 가 나옵니다. 이 창이 켜져 있는 동안만 동작합니다.
2. PC에서는 `http://localhost:8765`, 아이패드에서는 창에 나온 `http://192.168.x.x:8765` 주소를 Safari로 엽니다. 처음 한 번 접속 비밀번호를 묻습니다.
3. '이슈 키워드 10편' 탭 → **지금 바로 찾아서 쓰기**로 바로 시작할 수도 있습니다.
4. '검토·발행' 탭에서 글을 열어 고치고, 발행 시간을 정한 뒤 **예약 시간에 PC가 자동 발행**을 누릅니다.
5. 처음에는 **임시저장으로 시험**을 눌러 네이버 임시저장함에 글이 제대로 들어가는지 확인해 보세요.

PC가 켜질 때 자동으로 시작하려면: `Win + R` → `shell:startup` → 열린 폴더에 `실행.bat`의 바로가기를 넣습니다.

## 밖에서 아이패드로 쓰기

같은 와이파이가 아니면 PC 주소에 닿지 않습니다. 무료 앱 **Tailscale**을 PC와 아이패드에 설치하고 같은 계정으로 로그인한 뒤, PC의 Tailscale 주소(`100.x.x.x`)로 `http://100.x.x.x:8765` 를 엽니다.

## 설정 (`config.json`, 첫 실행 때 생김)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `auto_write` / `auto_write_time` | `true` / `"05:47"` | 매일 자동 작성 여부와 시각 |
| `posts_per_day` | `4` | 하루에 쓸 글 수 |
| `auto_publish` | `true` | 예약 시간이 된 글을 자동 발행 |
| `publish_mode` | `"publish"` | `"draft"`로 바꾸면 발행 대신 임시저장만 (시험용) |
| `headless` | `false` | `true`면 크롬 창을 띄우지 않고 발행 |
| `writer` | `"auto"` | `auto`(Claude Code 있으면 사용, 없으면 API) / `claude-cli` / `api` |
| `model` | `"claude-opus-5-5"` | API를 쓸 때 모델 |
| `port` / `pin` | `8765` / 자동 생성 | 검토 앱 주소 포트와 접속 비밀번호 |

설정을 바꾼 뒤에는 `실행.bat`을 다시 시작하세요.

## 문제가 생기면

- 발행이 실패하면 검토 앱에 이유가 나오고, `data/logs/` 폴더에 그 순간의 화면(`fail_….png`)과 기록(`blog_auto.log`)이 남습니다.
- **"로그인이 필요합니다"** → `네이버 로그인.bat`을 다시 실행해 로그인하세요.
- **"…버튼/칸을 찾지 못했습니다"** → 네이버가 글쓰기 화면을 바꾼 경우입니다. `data/logs`의 화면 캡처와 함께 Claude에게 알려 주면 `blog_auto.py`의 해당 부분을 고칠 수 있습니다.
- 네이버는 짧은 시간에 글을 많이 올리면 제한할 수 있습니다. 하루 1~2편씩 시간 간격을 두고 올리세요.
- 이 프로그램은 네이버 공식 API가 아니라 브라우저 화면을 대신 눌러 주는 방식입니다. 네이버 이용약관과 계정 보호 조치에 걸릴 수 있으니, 본인 계정으로 적당한 양만 쓰세요.

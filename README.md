# 블로그 글쓰기 도우미 (아이패드용)

팜로그랩 네이버 블로그(blog.naver.com/panlog-lab)에 올릴 글을 만드는 웹앱입니다.
설치 없이 아이패드 Safari에서 바로 쓸 수 있고, 티스토리도 고를 수 있습니다.

## 자동 순서
1. **매일 오전 5시 47분(한국 시간)** Claude 클라우드 작업이 웹에서 최신 뉴스·정부 발표를 검색해, 블로그 카테고리에 맞는 키워드 10개를 고릅니다. (건강·연예·투자·정치·사건사고는 제외, 최근 3주 안에 쓴 키워드도 제외)
2. 키워드마다 자료를 더 찾아보고, 찾은 자료만 근거로 3,000자 이상 글을 써서 앱의 '검토·발행'에 넣습니다. 참고한 기사·공고 링크도 함께 저장됩니다. 끝나면 휴대폰 알림이 옵니다.
3. 아이패드에서 글을 열어 [직접 쓰기] 자리에 내 경험을 채우고, 숫자·날짜를 확인한 뒤 선정합니다.
4. 선정한 글에 예약 일정을 넣고, 네이버 앱/사이트에 **직접 로그인**해서 붙여넣고 발행 → 예약으로 그 시간을 맞춥니다.

'이슈 키워드 10편' 탭의 '지금 바로 찾아서 쓰기'로 기다리지 않고 바로 실행할 수도 있습니다.
클라우드 작업은 claude.ai의 예약 작업(이름: 블로그 최신 이슈 글 10편 자동 작성)이며, 실행 시간 변경이나 중지는 Claude에게 말하거나 claude.ai에서 할 수 있습니다.

## 이미지 만들기
- 글마다 대표 이미지(썸네일), [사진] 자리마다 정리 카드, 마지막에 '한눈에 정리' 카드를 만듭니다. 크기는 1080×1080 PNG이고 색은 4가지 중에 고릅니다.
- 정리 카드는 6종류입니다: 순서(신청 방법 등), 체크리스트, 핵심 숫자(마감일·금액), 비교표, Q&A, TIP. 본문에 있는 사실만 쓰고 [공고 확인] 값은 넣지 않습니다.
- 매일 자동 작성되는 글에는 카드 내용이 함께 들어옵니다. 직접 쓴 글은 '사진 자리마다 이미지 만들기'를 누르세요.
- '② 본문+이미지 복사'는 본문의 [사진] 자리에 이미지를 끼워 한 번에 복사합니다. 네이버에서 이미지가 빠지면 '글자만 복사'를 쓰고 이미지는 저장해서 넣습니다.

## 화면 세 개
- **한 편 쓰기**: 주제·내 경험·참고 자료를 넣고 글 한 편을 만듭니다.
- **이슈 키워드 10편**: 요즘 뜨는 키워드를 붙여넣고(네이버 데이터랩·구글 트렌드 링크 제공) '글 주제 10개 잡기'를 누르면 카테고리와 주제가 잡힙니다. 10개가 안 되면 이번 달 시기별 이슈로 채웁니다(실시간 검색량은 아님). 고른 주제를 두 편씩 동시에 써서 10편이면 10분 안팎 걸립니다. 멈추면 '남은 글 이어서 쓰기'로 계속할 수 있습니다.
- **검토·발행**: 만든 글이 모두 모입니다. 상태(검토 대기 → 선정 → 예약 완료 → 발행 완료, 보류)로 거르고, 선정한 글에 '하루 1편 08:00'처럼 일정을 한꺼번에 넣습니다. 글을 열면 네이버에서 맞출 예약 시간이 함께 나옵니다.

## 예약 발행은 어떻게 되나요?
네이버는 외부 프로그램이 글을 올리는 공개 API를 제공하지 않아, 이 앱이 직접 발행 버튼을 누를 수는 없습니다.
대신 앱이 일정을 정해 주고, 붙여넣을 때 네이버 글쓰기의 **발행 → 예약**에서 그 시간을 맞추면 네이버가 그 시간에 올립니다.
예약을 마치면 앱에서 '예약 완료로 표시'를 누르세요.

글은 claude.ai 링크로 쓸 때 내 Claude 계정 저장소에 저장되어 다른 기기에서 열어도 그대로 보입니다. (`index.html` 단독 실행은 그 기기 브라우저에 저장)

## 만들어 주는 것
- 공백 제외 3,000자 이상 본문 (3,500 / 4,000자 선택 가능), 제목 후보 3개, 태그 8~12개
- 사진 넣을 자리 `[사진: 무엇을 어떻게 찍을지]` 5~7곳과 이미지 목록
- 대표 이미지(썸네일)와 '한눈에 정리' 요약 카드 (1080×1080 PNG, 색 4가지)

## 내가 쓴 것처럼 쓰는 규칙
- '내 경험·메모'에 적은 날짜, 숫자, 사람, 기분을 본문 곳곳에 녹입니다. 메모에 없는 경험은 지어내지 않고 `[직접 쓰기]` 자리로 남깁니다.
- 짧은 문장과 긴 문장을 섞고, 소제목마다 같은 구조를 반복하지 않습니다. 시작 방식도 글마다 바꿉니다.
- "알아보겠습니다", "결론적으로", "도움이 되셨길 바랍니다", "첫째·둘째" 같은 AI 글 티 나는 말을 쓰지 않습니다.
- 참고 자료를 붙여넣으면 금액·대상·기간은 그 자료에 있는 것만 씁니다. 없으면 `[공고 확인]` 자리로 남깁니다.
- 애드센스 승인 정리안의 규칙(자동글 티 나는 문구 금지, 확인일·출처 표시)도 들어 있습니다.

## 발행 전 점검
글자 수, AI 글 티 나는 말, 반복되는 말투, 같은 문장 끝맺음이 이어지는 곳, 사진 자리 수, 남은 `[직접 쓰기]`·`[공고 확인]` 자리를 확인합니다.
분량이 모자라면 '3,000자 채우기', 말투가 딱딱하면 '내 말투로 더 자연스럽게'를 누르세요.

## 쓰는 방법 두 가지
1. **claude.ai 링크** (API 키 필요 없음): 아이패드 Safari나 Claude 앱에서 엽니다. 처음 '글 만들기'를 누를 때 Claude 사용 허락을 한 번 묻습니다.
2. **`index.html` 단독 실행** (내 Anthropic API 키 사용): GitHub Pages 등에 올려 Safari에서 열고, 공유 버튼 → '홈 화면에 추가'.

## 처음 한 번 할 일
'카테고리 편집'을 눌러 내 네이버 블로그 카테고리 이름을 한 줄에 하나씩 적고 저장하세요. 이 기기에 저장됩니다.

## 블로그에 올리기
1. '네이버 글쓰기 열기'를 누릅니다. Split View로 나란히 두면 편합니다.
2. 제목 → 본문 → 태그 순서로 복사해 붙여넣고 카테고리를 고릅니다.
3. 대표 이미지를 맨 위에, `[사진]` 자리마다 사진을 넣고 표시 글자를 지웁니다.
4. 발행 → 예약에서 앱이 알려 준 시간으로 맞추고 발행합니다.

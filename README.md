# 블로그 글쓰기 도우미 (아이패드용)

주제와 메모만 넣으면 **네이버 블로그용 제목 후보 3개 · 본문 · 해시태그**를 만들어 주는 웹앱입니다.
설치 없이 아이패드 Safari에서 바로 쓸 수 있습니다.

## 쓰는 방법 두 가지

### 1) claude.ai 링크로 쓰기 (API 키 필요 없음)
claude.ai에 올린 링크를 아이패드 Safari나 Claude 앱에서 엽니다.
처음 ‘글 만들기’를 누를 때 Claude 사용 허락을 한 번 묻고, 내 Claude 계정 사용량으로 글을 만듭니다.

### 2) `index.html`을 직접 띄워서 쓰기 (내 Anthropic API 키 사용)
GitHub Pages 등으로 `index.html`을 올리고 Safari에서 열면, API 키를 넣는 칸이 나타납니다.
키는 그 기기의 브라우저에만 저장됩니다.
Safari 공유 버튼 → **홈 화면에 추가**를 누르면 앱처럼 아이콘으로 열 수 있습니다.

## 네이버 블로그에 올리기
1. ‘네이버 블로그 글쓰기 열기’를 누릅니다. (네이버 블로그 앱이 있으면 앱으로 열릴 수 있어요)
2. **① 제목 복사 → ② 본문 복사 → ③ 태그 복사** 순서로 붙여넣습니다.
   Split View로 두 화면을 나란히 두면 편합니다.
3. `[사진: …]` 자리에 사진을 넣고 발행합니다.

## 왜 '자동 발행'이 아니라 '복사·붙여넣기' 방식인가요?
- 네이버는 블로그 글쓰기 공개 API를 더 이상 제공하지 않아, PC용 자동 발행 프로그램은 대부분
  Selenium 같은 브라우저 자동 조종을 씁니다. 이런 방식은 아이패드(iPadOS)에서는 실행할 수 없습니다.
- 자동 로그인·자동 발행은 네이버 약관 위반이나 보호조치(캡차, 계정 제한)를 부를 수 있습니다.
- 그래서 글 작성은 AI가, 발행 버튼은 사람이 누르는 방식으로 만들었습니다.
